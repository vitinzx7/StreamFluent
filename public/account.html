Entrar

Com uma conta, você guarda uma cópia do seu estudo e continua de outro computador. Sem conta, tudo continua salvo neste navegador.

Para criar uma conta, use uma senha de pelo menos 8 caracteres e confirme pelo link enviado ao seu e-mail. Entrar não ativa a sincronização.

Sua conta

Pausar interrompe os próximos envios; uma solicitação já enviada pode terminar. Ao ativar de novo, as mudanças feitas neste dispositivo também são comparadas com a conta.

Sincronização

Desativada. Ativando, seu estudo é enviado para a conta e o que já estiver nela é trazido para cá.

O que vai para a conta

Frases salvas, palavras marcadas como difíceis ou aprendidas, os contextos delas e as preferências. O histórico de palavras apenas vistas fica neste dispositivo. Os provedores de tradução não recebem sua biblioteca.

Os dados da conta continuam lá depois de sair ou desinstalar. Esta biblioteca fica vinculada à primeira conta usada; para outra conta, use outro perfil do Chrome.

Escolha o que preservar

As duas cópias mudaram. Nenhuma delas será substituída até sua escolha. “Excluído” significa remover esse item.

Backup e dados

Seu estudo fica salvo neste navegador, e desinstalar a extensão apaga tudo. O backup é um arquivo com palavras, frases, histórico de palavras vistas e preferências, para guardar ou levar para outro computador.

O arquivo tem seus dados de estudo em texto e nenhuma senha ou dado de login. Importar junta o arquivo ao que já está aqui.

Apagar dados

Nível e preferências ficam. Exporte um backup antes se quiser guardar.
